Moonlit Museum: Sapphire Heist is a top-down stealth game in plain JavaScript and canvas: sneak a thief through five moonlit museum galleries — 20 guards, 14 cameras, 37 treasures, 17 laser tripwires — dodge guard flashlight cones and sweeping security cameras, read the dotted patrol routes (a paused guard still looks around), steal the Starlight Sapphire and every treasure you dare, and escape before the alarm meter fills. Each gallery is graded S/A/B/C on loot taken and how high the alarm climbed. No build step and no network requests — the game is static files under `game/`, with sound synthesized live in WebAudio.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
# play: WASD / arrow keys to move, hold SHIFT to sneak, M to mute
# or open game/index.html through any static file server
```
